# Operação Turno Crítico

Projeto desenvolvido em Python para simular o controle de turnos críticos.

## Objetivo

O objetivo do projeto é organizar e controlar informações relacionadas aos turnos, permitindo melhor visualização e acompanhamento dos dados.

## Funcionalidades

- Cadastro de informações do sistema
- Organização dos dados
- Consulta das informações cadastradas
- Estruturação do projeto em Python

## Tecnologias utilizadas

- Python
- GitHub

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto em um editor de código.
3. Execute o arquivo principal do projeto em Python.
